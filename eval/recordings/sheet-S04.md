## How to record

- Read each sentence once, in your normal speaking voice and pace, the way you would say it to a phone assistant.
- Say numbers the way you normally would, for example "eight forty rupees". Do not spell them out digit by digit.
- Record one file per sentence: 16 kHz mono WAV, named <take ID>.wav (for example S04-cmd-005-q.wav).
- If you make a mistake, record the sentence again under the same name. The new file replaces the old one.
- Do the blocks in the order shown. Set up the conditions before you start each block.
